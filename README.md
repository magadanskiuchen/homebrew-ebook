# Изкуството на домашното пивоварство - Ebook

Дигитално ръководство за домашно пивоварство в чист HTML5 и CSS формат.

## Характеристики
- **Без JavaScript**: Бързо зареждане и 100% стабилност.
- **Оптимизирана типография**: Комфортен размер за четене на десктоп и мобилни устройства.
- **Автоматична Тъмна Тема**: Поддържа светла "Paper/Amber" тема и системна тъмна тема (`prefers-color-scheme: dark`).
- **Ясни линкове**: Всяка секция и под-глава разполага с уникален HTML анкер за бърз bookmark и споделяне.

## Как да разгледате книгата
Отворете `index.html` във всеки браузър.
